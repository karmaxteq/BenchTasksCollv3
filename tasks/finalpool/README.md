# Final Pool Tasks Collection

This repository contains a collection of all implemented tasks from the BenchTasksCollv3 project, organized under `tasks/finalpool`. All tasks in this collection satisfy the implementation requirements.

## Overview

The finalpool branch aggregates tasks from all developers who have completed their implementations. Each task follows the standard structure:

```
task-name/
├── docs/          # Documentation files (agent_system_prompt.md, task.md)
├── evaluation/    # Evaluation scripts (main.py)
└── groundtruth_workspace/  # Ground truth data and verification files
```

## Implementation Criteria

Tasks are considered "implemented" when they meet the following criteria:
- Presence of required task structure (docs/, evaluation/main.py, groundtruth_workspace/)
- Non-empty configuration files with necessary fields

## Available Tasks

See individual task folders in `tasks/finalpool/[task-name]/` for detailed information about each implementation.
