# Sample Task Structure - coupon-manager

This is a sample task demonstrating the expected directory structure for all implementations.

## Files Required

Each implemented task must have the following structure:

```
task-folder/
├── docs/
│   ├── agent_system_prompt.md  # System prompt and instructions
│   └── task.md                 # Task description and requirements
├── evaluation/
│   └── main.py                 # Evaluation/validation script
└── groundtruth_workspace/      # Ground truth data and verification
    
    └── readme.txt              # Information about this workspace
```
